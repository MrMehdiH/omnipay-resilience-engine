# بازبینی اول: تفکر انتقادی و بازبینی فرض‌ها

تاریخ: ۱۵ نوامبر ۲۰۲۶. دامنه: کد، قراردادها، تست‌ها، گردش انتشار و خروجی استاتیک محلی.

این پروژه یک شبیه‌ساز آموزشی در مرورگر با هستهٔ مستقل TypeScript است. ارزش آن در نمایش و آزمودن تصمیم‌های پرداخت است؛ برای ادعای سامانهٔ توزیع‌شدهٔ عملیاتی، به ذخیره‌سازی پایدار، هماهنگی بین پردازه‌ها و اتصال واقعی به ارائه‌دهنده نیاز دارد.

## مبنای بررسی

- شاخهٔ محلی: `feature/resilience-simulation`؛ HEAD اولیه: `54da238`.
- `origin/main` بررسی‌شده: `47fdeccd236bf7772cea44e1522d2e84b791cdc2`؛ نیای مشترک: `c7207e9`.
- اصلاح استعلام نتیجهٔ مبهم از قبل در main موجود بود. پنج فایل مرتبط از main به درخت کاری منتقل شدند؛ این بخش دستاورد جدید این بازبینی محسوب نمی‌شود. تغییر نام محلی پیکربندی Vitest به `.mts` حفظ شد.
- ادغام سه‌طرفهٔ آزمایشی فایل‌های مرتبط تعارضی نشان نداد؛ هیچ merge، commit، push یا PR انجام نشد. تغییرات آیندهٔ main ممکن است نتیجه را عوض کنند.
- بازکردن سایت منتشرشده با `ERR_CONNECTION_RESET` روبه‌رو شد. نتیجه‌های مرورگر این گزارش مربوط به export محلی با base path انتشار هستند؛ سلامت سایت عمومی تأیید نشده است.

## اولویت‌های مرحلهٔ بعد

1. **Circuit breaker واقعی:** ماشین حالت Closed/Open/Half-open، clock تزریقی، محدودیت probe هم‌زمان و تست recovery. enum وضعیت به‌تنهایی قابلیت نیست.
2. **بودجهٔ زمانی و مالکیت قفل:** timeout و cancellation برای portهای معلق، lease renewal و fencing. TTL فعلی جایگزین این‌ها نیست.
3. **پایداری مالی:** adapter سرور، idempotency و دفترکل پایدار، reconciliation قابل ادامه پس از restart و هماهنگی بین چند پردازه. cache یک tab تضمین توزیع‌شده نمی‌دهد.
4. **قراردادهای رشد:** انتقال قراردادهای باقی‌ماندهٔ growth از core به schemas و اعتبارسنجی تمام ورودی‌های عمومی آن؛ بررسی محدودیت حافظهٔ ledger و رجیستری در اجرای طولانی.
5. **تست UI خودکار:** EN/FA، صفحهٔ باریک، keyboard، accessibility، failure و replay در CI؛ local smoke جای این لایه را نمی‌گیرد.
6. **آمادگی انتشار:** تأیید تنظیمات حفاظت main و Pages، انتخاب مجوز توسط مالک، پاکسازی assetهای پیش‌فرض و بازبینی metadata اشتراک‌گذاری.

برای این مرحله ادعای «production-ready» یا «بدون خطا» قابل دفاع نیست. ادعای دقیق‌تر: شبیه‌ساز قابل آزمون با رفتارهای ایمنی روشن و محدودیت‌های مستند.
